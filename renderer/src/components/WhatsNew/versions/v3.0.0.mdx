A huge release packed with new features — the biggest update since launch!

- **Arena (PvP)** — challenge other players to real-time typing battles. Race head-to-head and see who's faster.
- **Typing Streaks** — build and protect your daily practice streak. Use streak freezes to keep your streak alive on days you miss.
- **Code Mode** — practice typing real code snippets. Handles indentation, newlines, and language-specific syntax.
- **More keyboard layouts** — Colemak-DH, UK QWERTY (ISO), Nordic SE, Brazilian ABNT2, Italian QWERTY, and NZ QWERTY added.
- **More languages** — Italian, Portuguese (BR), Dutch, and an expanded Māori wordset (7,700+ words).
- **App language / translations** — the UI now follows your system language, with support for French, German, Spanish, Italian, Portuguese, Dutch, and Māori. Manually override or let the app auto-detect.
- **Preferred keyboard suggestions** — the app now suggests the right keyboard layout for your selected language.
- **New stats display** — the practice stats row has been redesigned into a compact pill strip.
- **Revamped settings** — left-side category navigation makes it easier to find what you're looking for.
